# siiiift-backend  

siiiift Backend 🍰  

An AI-powered baking journal backend that provides feedback on bakes through image and recipe analysis.  

About  

siiiift helps bakers track their journey by analyzing bakes, managing recipes, and providing AI-powered feedback. This repository contains the backend code that powers the siiiift platform.  

Features  


🍩 Recipe Management: Save recipes from URLs or images to your personal recipe box  

🥧 Social Sharing: Share your baking experiences with other bakers  

🍪 AI Feedback: Leverage Google Gemini for intelligent analysis of images and recipes  

🥐 No Hands Baking: Voice-controlled recipe navigation for hands-free baking assistance  

 
Tech Stack  


Framework: Node.js and Express  

Hosting: Render  

Database & Auth: Supabase (Database, Storage, Authentication, Edge Functions)  

AI & Processing:  


* Google Gemini for AI analysis
* Cheerio for web scraping recipes
* Sharp for image processing


Voice: Web Speech API integration
Development Tools:

* ESLint and Prettier for code quality
* Jest and Supertest for testing
* Bottleneck for API rate limiting
